
# 📘 Assignment: Hangman Game

## 🎯 Objective

Build a word-guessing game in Python to practice string manipulation, loops, conditionals, random selection, and user input.

## 📝 Tasks

### 🛠️ Build the Hangman Game

#### Description
Create a Hangman game where players guess letters to reveal a randomly selected hidden word before running out of attempts.

#### Requirements
Completed program should:

- Randomly select a word from a predefined list
- Accept letter guesses and show the current progress (for example, `_ _ _`)
- Track and display the number of incorrect guesses remaining
- End when the word is guessed or the player runs out of attempts
- Display a clear win or loss message
